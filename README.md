# Student Portfolio & Academic Management Website

A responsive, mobile-friendly multi-page student portfolio built with plain HTML5, CSS3, and JavaScript.

## Folder Structure
- `index.html` — Homepage with portrait photo, welcome greeting, navigation, and bio
- `about.html` — Educational background, career aspirations, skills, hobbies, course table, and audio welcome
- `projects.html` — Three sample projects with screenshots, links, and walkthrough video
- `planner.html` — Interactive JavaScript Academic Planner (add, complete, delete, and filter tasks)
- `contact.html` — Contact form with JavaScript validation (non-empty fields, valid email, digits-only phone)
- `css/style.css` — External responsive stylesheet (Flexbox, CSS Grid, mobile menu, animations)
- `js/script.js` — External JavaScript file for navigation, task management, and form validation
- `images/` — Profile image, project screenshots, and video poster
- `media/` — Audio welcome file (`intro.wav`) and video demo (`project-demo.mp4`)

## Personalizing Your Site
1. Replace `images/profile.png` with your own photo (keep the filename `profile.png` or update `index.html`).
2. Replace `Mfonobong Iniobong Tommy` and the sample details in the HTML files with your own name, courses, and links.
